> **삼익제약(014950) DART 자동 크롤링 & 재무분석 대시보드**  
> 본 저장소는 DART Open API를 연동하여 매월 1일 삼익제약의 사업/반기/분기 보고서를 자동 수집하고 재무 비율을 분석하여 대시보드 형태로 제공합니다.

---

## 📌 주요 기능
1. **DART 수집 연도**: 2010년 ~ 현재
2. **수집 대상 보고서**: 사업보고서, 반기보고서, 분기보고서
3. **자동 업데이트**: GitHub Actions를 통한 매월 1일 자동 실행
4. **시각화 대시보드**: GitHub Pages 배포 (`/docs` 폴더 기반)
